
# Job Scheduler & Automation Dashboard

## Overview
Mini automation engine to create, run, and track background jobs with webhook notifications.

## Tech Stack
- Frontend: Next.js
- Backend: Node.js, Express
- Database: MySQL

## Setup
1. Run database/schema.sql
2. Backend: npm install && npm run dev
3. Frontend: npm install && npm run dev

## APIs
POST /jobs  
GET /jobs  
GET /jobs/:id  
POST /jobs/run-job/:id  

## Webhook
Triggered on job completion.

## AI Usage
ChatGPT (GPT-4) used for architecture and documentation.
